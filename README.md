# Talleres Extracurriculares

Sistema para la gestión e inscripción de talleres extracurriculares.

## Proyecto Desplegado
Puedes ver la aplicación funcionando en Render:
https://taller-extracurriculares.onrender.com

##  Tecnologías
- Node.js y Express
- HTML, CSS y JavaScript
